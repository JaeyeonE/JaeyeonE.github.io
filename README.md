# jaeyeone.github.io

Personal portfolio. React + TypeScript + Vite, react-three-fiber for the
interactive hero, Tailwind CSS v4 for styling. Deploys to GitHub Pages via
`.github/workflows/deploy.yml` on push to `main`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
npm run preview
```

## Content

All resume/project copy lives in `src/data/content.ts` — edit there rather
than in the components.
